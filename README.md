## Sobre mim

<img align="right" src="./assets/coding-animation.gif" width="26%" alt="Desenho animado de uma pessoa de costas digitando no computador, com um gato ao lado." />

Sou **Carlos Leonel** Curso **Desenvolvimento de Software Multiplataforma na Fatec**, em São Paulo. sou desenvolvedor de software direcionando minha carreira para **Engenharia de Dados**. Tenho experiência prática com **Python, PySpark, Palantir Foundry e TypeScript**.

Minha base em **backend, APIs e modelagem relacional** ajuda na construção de aplicações ao tratamento dos dados que elas produzem e consomem.
